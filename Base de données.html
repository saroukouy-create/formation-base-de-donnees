🔹 1. Qu'est-ce qu'une base de données ? (explication simple)

Une base de données est comme un classeur géant où vous rangez des informations (clients, produits, messages…). Le SQL est le langage qui vous permet de ranger, chercher et modifier ces informations.

Imaginez que vous avez un fichier Excel avec des onglets : chaque onglet est une table, chaque ligne est un enregistrement et chaque colonne est une propriété (nom, prix, date…).

📌 Modèle ACID — Atomicité, Cohérence, Isolation, Durabilité — garantit la fiabilité des transactions.

🔹 2. Fondamentaux du langage SQL

📋 Principales commandes

  • DDL (Data Definition Language) : CREATE, ALTER, DROP
  • DML (Data Manipulation Language) : SELECT, INSERT, UPDATE, DELETE
  • DCL (Data Control Language) : GRANT, REVOKE
  • TCL (Transaction Control) : COMMIT, ROLLBACK, SAVEPOINT
-- Exemple de création de table et requête SELECT CREATE TABLE clients ( id INT PRIMARY KEY, nom VARCHAR(50), email VARCHAR(100) UNIQUE, date_inscription DATE ); INSERT INTO clients VALUES (1, 'Dupont', 'dupont@mail.com', '2025-01-15'); SELECT nom, email FROM clients WHERE date_inscription > '2025-01-01';

🔗 Jointures & agrégations

INNER JOIN, LEFT JOIN, GROUP BY, HAVING, fonctions d'agrégation (COUNT, SUM, AVG, MAX, MIN).

🖥️ pgAdmin : interface d'administration pour PostgreSQL

pgAdmin est l'outil graphique de référence pour PostgreSQL. Il permet de gérer les bases, exécuter des requêtes, visualiser les plans d'exécution, gérer les rôles, les sauvegardes, etc.

📱 SQLite

  • Desktop (logiciels légers)

⬇️ 5. Comment installer chaque base (même sans technique)

Ne vous inquiétez pas : je vais vous guider comme si vous n'aviez jamais installé un logiciel. Suivez les étapes une par une.

📦 SQLite — La plus simple

🔹 C'est quoi ? SQLite est une base de données qui tient dans un seul fichier. Pas de serveur à lancer, pas de mot de passe. Parfait pour commencer.
  1. Allez sur le site : sqlite.org/download.html.
  2. Téléchargez le fichier pour Windows : “sqlite-tools-win32-x86-*.zip” (ou “win64” si vous avez un PC récent). Pour Mac, prenez “sqlite-tools-osx-x86-*.zip”.
  3. Extrayez le dossier : faites un clic droit sur le fichier .zip → “Extraire tout”. Vous verrez un fichier sqlite3.exe.
  4. Pour l'utiliser : double-cliquez sur sqlite3.exe. Une fenêtre noire (terminal) s'ouvre. Vous pouvez taper des commandes SQL.
💡 Conseil : Pour une interface graphique (plus facile), téléchargez DB Browser for SQLite (gratuit). Vous pourrez voir vos tables comme dans Excel.

🐬 MySQL — Le plus populaire

🔹 C'est quoi ? MySQL fonctionne comme un serveur : il tourne en arrière-plan et votre application s'y connecte.
  1. Rendez-vous sur : mysql.com/downloads.
  2. Cliquez sur “MySQL Community Server” (la version gratuite).
  3. Téléchargez l'installateur : pour Windows, prenez “mysql-installer-web-community-*.msi”. Pour Mac, le .dmg.
  4. Lancez l'installateur : double-cliquez et suivez les étapes. Laissez les options par défaut (ne changez rien).
  5. Mot de passe : quand on vous demande un mot de passe pour “root”, écrivez-en un facile (ex: root123) et notez-le sur un papier.
  6. Fin de l'installation : MySQL est maintenant installé. Vous pouvez utiliser MySQL Workbench (installé avec) pour une interface graphique.
🖥️ Interface graphique : MySQL Workbench est installé automatiquement. Ouvrez-le, vous pourrez créer des bases en cliquant.

🦭 MariaDB — Le remplacement de MySQL

🔹 C'est quoi ? MariaDB est presque identique à MySQL, mais avec plus de fonctionnalités.
  1. Allez sur : mariadb.org/download.
  2. Téléchargez l'installateur : pour Windows, le fichier “.msi”. Pour Mac, le “.pkg”.
  3. Lancez l'installateur : suivez les étapes, laissez les valeurs par défaut. Notez le mot de passe root.
🔄 Astuce : MariaDB utilise les mêmes commandes que MySQL. Vous pouvez utiliser les mêmes outils (MySQL Workbench, HeidiSQL).

🐘 PostgreSQL + pgAdmin — Le plus complet

🔹 C'est quoi ? PostgreSQL est une base de données très puissante. pgAdmin est une interface graphique qui ressemble à un site web.
  1. Rendez-vous sur : postgresql.org/download.
  2. Choisissez votre système :
    • Windows : téléchargez l'“Interactive installer” (.exe).
    • Mac : le .dmg.
  3. Lancez l'installateur : suivez les étapes. L'installateur inclut pgAdmin (cochez-le).
  4. Mot de passe : on vous demandera un mot de passe pour l'utilisateur “postgres”. Notez-le.
  5. Port : laissez 5432.
  6. Une fois installé : cherchez “pgAdmin” dans le menu Démarrer. Ouvrez-le, une page web s'ouvre dans votre navigateur.
🎯 Première connexion : dans pgAdmin, cliquez sur “Ajouter un serveur” → donnez un nom (ex: “MaBase”) → utilisateur postgres et votre mot de passe.

🔗 6. Comment relier votre base de données à votre application ?

Vous avez installé votre base. Maintenant, vous voulez que votre site web, votre logiciel ou votre application puisse lire et écrire des données dedans. Pas de panique, je vous explique sans jargon technique.

📌 Le principe en 3 points :
  1. Votre application demande à la base de données de lui donner des informations (ex: "donne-moi la liste des clients").
  2. La base répond avec les données.
  3. Pour que ça fonctionne, votre application doit connaître l'adresse de la base, le nom de la base, et un mot de passe.

🔹 Cas 1 : Votre application est sur votre ordinateur (en local)

Vous développez sur votre PC. La base est installée sur le même ordinateur.

📌 Les informations de connexion (locales) :

  • Hôte (adresse) : localhost ou 127.0.0.1 (cela signifie "mon propre ordinateur").
  • Port : 3306 pour MySQL/MariaDB, 5432 pour PostgreSQL. Pour SQLite, pas de port.
  • Nom de la base : le nom que vous avez donné à votre base (ex: ma_base).
  • Utilisateur : root (MySQL/MariaDB) ou postgres (PostgreSQL).
  • Mot de passe : celui que vous avez noté lors de l'installation.

Exemple avec Python (MySQL) :

import mysql.connector # Paramètres de connexion conn = mysql.connector.connect( host="localhost", port=3306, user="root", password="votre_mot_de_passe", database="ma_base" ) cursor = conn.cursor() cursor.execute("SELECT * FROM clients")

Pour SQLite : c'est encore plus simple, vous donnez juste le chemin du fichier .db.

import sqlite3 conn = sqlite3.connect('ma_base.db') # chemin du fichier cursor = conn.cursor() cursor.execute('SELECT * FROM clients')

🔹 Cas 2 : Votre application est sur un hébergeur (site web en ligne)

Vous avez un site web chez un hébergeur (OVH, Hostinger, AlwaysData, etc.). La base de données est fournie par l'hébergeur.

📌 Où trouver les informations de connexion ?

  • Connectez-vous à l'espace client de votre hébergeur.
  • Cherchez la section “Bases de données” ou “MySQL” / “PostgreSQL”.
  • Vous verrez quelque chose comme :

Exemple d'informations fournies :

  • Hôte : mysql-votre-site.alwaysdata.net
  • Port : 3306
  • Base de données : votre_base_123
  • Utilisateur : votre_utilisateur
  • Mot de passe : celui que vous avez choisi (ou généré par l'hébergeur)

Dans votre code : vous remplacez localhost par l'hôte distant.

// Exemple en PHP pour un site hébergé $host = 'mysql-votre-site.alwaysdata.net'; $port = 3306; $dbname = 'votre_base_123'; $user = 'votre_utilisateur'; $pass = 'votre_mot_de_passe'; $pdo = new PDO("mysql:host=$host;port=$port;dbname=$dbname", $user, $pass);
⚠️ Attention : ne mettez jamais vos mots de passe en clair dans le code que vous publiez. Utilisez un fichier .env (votre hébergeur vous explique comment faire).

🔹 Cas 3 : GitHub et la base de données

GitHub n'héberge pas de bases de données. C'est un endroit pour stocker votre code. Mais voici comment gérer votre base avec GitHub.

📌 Que faire avec ma base sur GitHub ?

  • Ne mettez pas le fichier .db (SQLite) sur GitHub — il contient vos données. Ajoutez-le dans un fichier .gitignore.
  • Mettez plutôt les scripts SQL qui créent vos tables (ex: schema.sql). Comme ça, d'autres développeurs peuvent recréer la structure.
  • Les mots de passe : ne les mettez JAMAIS dans votre code sur GitHub. Utilisez un fichier .env (exclu par .gitignore).

Exemple de fichier .gitignore :

# Ignorer les fichiers de base de données *.db *.sqlite *.sqlite3 .env # Ignorer les fichiers de configuration sensibles config/database.yml

Exemple de fichier schema.sql que vous pouvez versionner :

-- Ce fichier est sur GitHub, il contient la structure de la base CREATE TABLE clients ( id SERIAL PRIMARY KEY, nom VARCHAR(100) NOT NULL, email VARCHAR(100) UNIQUE ); -- Ajoutez ici toutes vos tables
🔐 Sécurité : N'oubliez jamais de ne pas committer vos mots de passe, clés API ou données personnelles. Utilisez un fichier .env (exclu par .gitignore) pour stocker ces informations.

🛠️ Étapes communes pour connecter votre application

  1. Installez le driver correspondant à votre langage et à votre SGBD (ex: pip install mysql-connector-python, npm install pg, composer require pdo-mysql).
  2. Configurez les paramètres de connexion (hôte, port, nom de base, utilisateur, mot de passe).
  3. Testez la connexion avec un script simple avant d'aller plus loin.
  4. Utilisez des requêtes préparées pour éviter les injections SQL.
  5. Gérez les erreurs (try/catch, exceptions) pour que votre application ne plante pas si la base est inaccessible.

💡 7. Exemples concrets pour bien comprendre

📌 Exemple 1 : Votre site WordPress

WordPress utilise MySQL. Quand vous installez WordPress, il vous demande le nom de la base, l'utilisateur et le mot de passe. C'est tout ! WordPress gère la connexion tout seul.

📌 Exemple 2 : Une application mobile avec SQLite

SQLite est parfait pour les applis mobiles. La base est un fichier dans le téléphone. L'application lit et écrit dans ce fichier. Pas de serveur, pas de mot de passe.

📌 Exemple 3 : Un site e-commerce avec PostgreSQL

Vous avez un site de vente en ligne. La base de données est hébergée chez OVH. Dans le code du site, vous avez un fichier .env avec les identifiants. Le site se connecte à la base pour afficher les produits.

❓ 8. Questions fréquentes (sans technique)

  • Je ne comprends rien aux commandes, est-ce que je peux quand même utiliser une base ? Oui ! Utilisez les interfaces graphiques : DB Browser (SQLite), MySQL Workbench (MySQL), pgAdmin (PostgreSQL). Vous pouvez tout faire en cliquant.
  • Mon hébergeur me donne une base, comment je m'en sers ? Dans votre espace client, vous avez les identifiants. Vous les copiez dans le fichier de configuration de votre site (souvent un fichier .env).
  • Est-ce que je peux avoir plusieurs bases sur mon ordinateur ? Oui, vous pouvez installer MySQL, PostgreSQL et SQLite en même temps. Elles utilisent des ports différents.
  • Comment sauvegarder ma base ? Pour SQLite, copiez le fichier .db. Pour MySQL/PostgreSQL, utilisez les outils d'export (phpMyAdmin, pgAdmin, ou la commande mysqldump).
  • Que faire si j'oublie mon mot de passe root ? Pas de panique ! Vous pouvez réinitialiser le mot de passe en suivant les instructions de votre SGBD (recherchez sur Google “réinitialiser mot de passe MySQL”).
  • Que faire si je ne peux pas me connecter à la base distante ? Vérifiez que l'hôte, le port et les identifiants sont corrects. Certains hébergeurs restreignent les connexions externes ; utilisez leur panel pour autoriser votre IP.
